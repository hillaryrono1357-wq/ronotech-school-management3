# RonoTech Commercial Product Edition

First run: npm install, then npm start. The setup wizard captures school details, logo, license, and administrator. Demo Mode uses separate DEMO state. Administration includes signed license activation/renewal, automatic backups (startup + every 6 hours), download and restore. School branding is used by the dashboard, printable reports, report cards, and receipts. A future cloud edition can reuse the UI/API with hosted tenant data and online billing while retaining this Local/LAN edition.
