# RonoTech Commercial Licensing

The school application verifies digitally signed licenses using an Ed25519 public key. The matching private key must be kept outside every customer installation.

## Customer workflow
1. Install the RonoTech School Management System.
2. Give the school a license key generated by RonoTech.
3. During first-run setup, enter the school name and license key.
4. The system verifies the signature, school name and expiry date.
5. Future renewals must use the same school/site ID and school name.

## RonoTech owner workflow
Use the separate **RonoTech License Manager** package. Do not copy the private key into the school system ZIP.

Suggested plans:
- Trial — short evaluation period.
- Standard — normal school installation.
- Premium — use for a higher commercial package when you define additional features/support.

Keep a separate record of each customer's school ID, license number, installation date, expiry date and support terms.
