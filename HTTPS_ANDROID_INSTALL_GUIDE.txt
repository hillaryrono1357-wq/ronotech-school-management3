HTTPS AND ANDROID APP INSTALLATION

This package provides an Android-installable web app (PWA), not an APK.
It has a home-screen icon, a standalone window, offline reopening and sync.

UPDATE THE HOST
1. Sync pending offline changes on every device before switching to HTTPS.
   Browser storage for HTTP and HTTPS is separate.
2. Stop the school system. Copy all files/folders from this package EXCEPT
   data and node_modules over the existing installation. Keep the existing
   data and node_modules folders. This retains current school records.
3. Reserve a fixed host IP in the router (ask your network administrator).
4. Run CONFIGURE HTTPS.bat under your usual Windows account. This version
   uses Windows 10/11 built-in certificate tools and does not require mkcert.
5. Approve the local certificate trust prompt if Windows asks. Wait for
   SUCCESS. See WINDOWS_NATIVE_HTTPS_GUIDE.txt for detailed setup steps.
6. Start the system using START SCHOOL SYSTEM.bat. The host now prints and
   opens an https:// address using the normal port. If the firewall blocks
   access, allow Node.js on the private school network using the existing
   ALLOW SCHOOL NETWORK.bat as administrator.

INSTALL ON ANDROID
1. Copy ONLY tls/RonoTech-Root-CA.crt from the host to the phone using USB
   or another trusted transfer. Never copy rootCA-key.pem/server-key.pem.
2. Android Settings > Security (or Security and privacy) > More security
   settings > Encryption and credentials > Install a certificate > CA
   certificate. Menu names vary by phone. Select RonoTech-Root-CA.crt.
   Only install the certificate generated by your own trusted school host.
3. Connect the phone to the school's Wi-Fi. Open Chrome and visit the
   exact HTTPS LAN address printed by the host, such as
   https://192.168.1.10:3004 (example only; use your actual IP and port).
4. There must be no certificate warning. Bypassing a warning is not enough
   for reliable offline installation. Check the host IP and CA trust first.
5. Sign in and open the records/marks pages you need. Allow initial assets
   and records to finish loading while connected.
6. Tap Install RonoTech App if shown, or Chrome's menu > Add to Home screen
   > Install (wording may differ). Open the RonoTech icon and sign in once
   while connected if necessary.
7. The installed app can reopen offline using its cached shell and saved
   session. Do not log out or clear app/browser storage while offline.
   Saved changes sync when the same HTTPS host becomes reachable.
   If the host session expires, sign in online again with the same account.
   Account administration and full backup/restore still require the host.

IMPORTANT
This local HTTPS setup does not make the school accessible over the internet.
A separate mobile-data network cannot reach the school's LAN on its own.
Browser support and device policy determine whether installation is offered;
Android devices managed by an organization may block CA installation.
If the host IP changes, rerun HTTPS configuration and use the new address.
Changing the address or port creates a different offline-storage origin.
Keep the existing certificates/CA when updating the app, and never distribute
private keys. Remove the CA from phones when access is no longer needed.
The Windows setup and Android installation must be completed on the actual
host/devices; this package cannot install trust remotely.
